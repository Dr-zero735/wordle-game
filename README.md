# wordle-game
In this project, i made a wordle game that choose a random word with length of 5 characters and you get 5 chances to guess the right word

if you get an existing character in the right place it's color will be green 🟩
if you get an existing character but not in it's right place it's color will be yellow 🟨 
if the character doesn't exist it's color will be red 🟥

guess the right word and win the game
